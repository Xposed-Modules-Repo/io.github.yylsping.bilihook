# 哔哩哔哩 7.42.0 播放器 UI 自动化操作避坑指南

设备：PLQ110（2800x1272，竖屏 1272x2800），通过 `adb -s 10.221.74.157:45555 shell "input ..."` 操控。

## 核心坑：控制栏按钮会快速自动隐藏

播放器控制栏（含右下角全屏按钮、画质按钮、Hi-Res 开关等）在点按视频唤出后**只停留约 1~2 秒**就会重新隐藏。因此：

- **绝对不要**把「唤出控制栏」和「点目标按钮」拆成两条 adb 命令执行——两次工具调用之间的延迟必然超过按钮存活窗口，点上时按钮已消失，表现为"点了没反应"。
- 必须把整套动作压进**一条** shell 命令，用 `sleep 0.5~0.8` 衔接。

## 竖屏进全屏（已验证可用）

```bash
adb shell "input tap 636 450; sleep 0.6; input tap 1188 778; sleep 2.5"
```

- `tap 636 450`：点视频中部唤出控制栏（如果控制栏本来已显示，这一下会把它关掉，后续点全屏必失败——所以最好先截图确认控制栏当前是隐藏的）。
- 0.6s 内 `tap 1188 778`：竖屏控制栏右下角全屏按钮（bounds 约 `[1111,702][1272,856]`，中心 ≈ (1191,779)；带 Hi-Res 角标的视频该位置附近是角标，全屏按钮在其右侧，注意区分）。
- 横屏后点中心唤出横屏控制栏：`input tap 1400 600; sleep 0.7` 后立即截图，画质标签在右下角（"倍速" 右侧，如 `4K` / `1080P`+`60帧` 小字）。

## 通用节奏模板（画质切换、Hi-Res 开关同理）

```bash
adb shell "input tap <唤出控制栏>; sleep 0.6; input tap <目标按钮>; sleep 0.6; input tap <列表项/开关>"
```

每一步间隔控制在 1 秒以内；需要截图留证时接在同一命令末尾：
`...; sleep 0.7; su -c 'screencap -p /data/local/tmp/processing/screen.png'`，随后 `adb pull`。

## 其他注意事项

- **先用长视频演练**（≥3 分钟，如风景/音乐视频）。短视频（十几秒）会在操作中途播完跳到播完推荐页，所有按钮坐标失效；必要时先点暂停（竖屏控制栏左下角 ≈ (78,778)）再慢慢操作，暂停状态进全屏后依然暂停，时间不限。
- 竖屏页面坐标系是 1272x2800，横屏全屏后变成 2800x1272，两套坐标不要混用。
- uiautomator dump **抓不到**播放器控制栏的节点（bbplayer_* 自绘 View，不在无障碍树里），不要指望用 resource-id 定位，只能用截图+固定坐标。
- 模拟点按不进全屏时，先排查是不是上一步把控制栏点没了，再排查坐标；不要无脑重复同一条命令。
